# Predict from a Ridge Regression Model

Computes predictions using a fitted ridge_model object.

## Usage

``` r
# S3 method for class 'ridge_model'
predict(object, newdata, ...)
```

## Arguments

- object:

  An object of class ridge_model.

- newdata:

  A numeric matrix or data frame containing new predictors.

- ...:

  Additional arguments.

## Value

A numeric vector of predicted values.
